2. Recomendaciones de Pegado (Sisa)

  • Paredes Exteriores vs Interiores: Para cerramientos exteriores usa bloque de 15 cm. Para divisiones de cuartos o baños usa bloque de 10 cm para optimizar metros cuadrados habitables.
  • Uso de INTACO / Premezclados: Si usas bloque artesanal con bordes irregulares, el mortero INTACO Capa Gruesa / Pegablock compensa las diferencias de medida fácilmente.
  • Chicotes de Varilla: Coloca varilla de 8mm amarrada a las columnas cada 3 hiladas para evitar fisuras por sismos.
